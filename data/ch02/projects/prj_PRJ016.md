# Insurance Claims Automation

## Project Overview

Intelligent automation of claims processing using AI, machine learning, and robotic process automation. This strategic initiative for NationWide Insurance aimed to transform their operations in the Insurance sector, leveraging cutting-edge technologies and methodologies to achieve significant business impact.

## Client Profile

NationWide Insurance is a leading organization in the Insurance industry that partnered with OMG Consulting to intelligent automation. The project was conducted between 2020-10-01 and 2021-08-31 with a budget of 2300000-3500000.

## Team Composition

## Technologies and Methodologies

This project utilized a modern technology stack including:

- Azure Functions
- AWS Lambda
- Spring Boot
- Node.js
- Event-Driven Architecture

## Key Challenges

The project presented several significant challenges:

- Limited availability of subject matter experts for critical components
- Legacy system dependencies that couldn't be easily modernized
- Resistance to change from key stakeholders and end users
- Complex security and compliance requirements

## Outcomes and Business Impact

The project delivered substantial value to NationWide Insurance:

- Deployed 6 new AI/ML models that improved decision accuracy by 35%
- Achieved 3x improvement in system performance, handling 56K requests per minute at peak
- Improved customer satisfaction scores by 1.6 points, reaching an all-time high of 9.6/10

## Lessons Learned and Best Practices

This engagement yielded valuable insights that informed OMG Consulting's approach to future intelligent automation projects:

- Building a robust communication framework early in the project was critical to success
- Implementing a phased approach allowed for incremental value delivery while managing risk
- Establishing clear governance and decision-making processes helped navigate complex stakeholder requirements
- Investing in knowledge transfer and documentation ensured sustainable long-term value for the client
