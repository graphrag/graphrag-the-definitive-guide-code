# Wealth Management Platform

## Project Overview

Modern wealth management platform with advisory capabilities, portfolio management, and client experience enhancement. This strategic initiative for Heritage Investments aimed to transform their operations in the Financial Services sector, leveraging cutting-edge technologies and methodologies to achieve significant business impact.

## Client Profile

Heritage Investments is a leading organization in the Financial Services industry that partnered with OMG Consulting to financial technology. The project was conducted between 2020-07-15 and 2021-12-31 with a budget of 2500000-4000000.

## Team Composition

OMG Consulting deployed a cross-functional team of 4 consultants to execute this project.

- **UX Design**: Michelle Wong (Digital Experience) - Client experience design, advisory interface, mobile application design

## Technologies and Methodologies

This project utilized a modern technology stack including:

- API Gateway
- AWS CloudFront
- React
- AWS Lambda
- Spring Boot

## Key Challenges

The project presented several significant challenges:

- Geographic distribution of team members across multiple time zones
- Legacy system dependencies that couldn't be easily modernized
- Performance and scalability challenges during peak usage periods
- Strict regulatory compliance requirements in a rapidly changing landscape

## Outcomes and Business Impact

The project delivered substantial value to Heritage Investments:

- Expanded digital capabilities, resulting in 47% increase in digital channel adoption
- Unified customer view across all channels, increasing cross-sell opportunities by 29%
- Implemented real-time analytics capabilities, reducing reporting latency from days to minutes

## Lessons Learned and Best Practices

This engagement yielded valuable insights that informed OMG Consulting's approach to future financial technology projects:

- Building a robust communication framework early in the project was critical to success
- Implementing a phased approach allowed for incremental value delivery while managing risk
- Establishing clear governance and decision-making processes helped navigate complex stakeholder requirements
- Investing in knowledge transfer and documentation ensured sustainable long-term value for the client
